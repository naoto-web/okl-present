応募規約

本規約は、OKL（以下「当方」といいます）が実施する「視聴者プレゼント企画」（以下「本企画」といいます）への応募に関する条件を定めるものです。本企画に応募された方は、本規約に同意したものとみなします。

第1条（主催者）

本企画の主催者は OKL（運営責任者：Y）です。

本企画は当方が独自に実施するものであり、YouTube および Google LLC とは一切関係がありません。本企画に関するお問い合わせは、YouTube ではなく第13条の窓口までお願いいたします。

第2条（応募期間）

応募ページに掲載のとおり

応募期間の終了後に送信された応募は、理由の如何を問わず無効となります。

第3条（応募資格）

次のすべてを満たす方に限ります。

  1. 応募時点で満20歳以上であること
  2. 日本国内にお住まいで、日本国内の住所に賞品を受け取れること
  3. 本規約およびプライバシーポリシーに同意いただけること

※20歳未満の方からの応募はお受けできません。

第4条（賞品および当選者数）

当選者は合計20名様です。

  • 賞品の換金・返品・交換・第三者への譲渡はできません
  • 当選する権利を第三者に譲渡することはできません
  • やむを得ない事情により、同等以上の他の賞品に変更する場合があります

第5条（応募方法）

  1. 本企画の応募ページのフォームに、必要事項（メールアドレス、ニックネーム、希望賞品ほか）を入力して送信してください
  2. 応募はお一人様1回限りです。同一のメールアドレスからの2回目以降の応募は無効となります
  3. 応募に必要な通信料・接続料は応募者のご負担となります
  4. 応募受付の確認メールは送信されません。送信完了画面の表示をもって受付完了とさせていただきます

第6条（抽選および当選発表）

  1. 応募期間の終了後、当方において厳正な抽選を行います
  2. 当選発表は、当選者ご本人へのメール通知をもって代えさせていただきます。落選された方へのご連絡はいたしません
  3. 抽選の方法・結果および選考過程に関するお問い合わせにはお答えできません
  4. 当選者のニックネームを、当方の配信または動画内で公表する場合があります。本名・住所等の情報を公表することはありません

第7条（当選後の手続き）

  1. 当選者には、応募時にご登録いただいたメールアドレス宛に当選通知をお送りします
  2. 当選通知に記載された専用URLから、通知日を含めて7日以内に賞品の発送先情報（氏名・郵便番号・住所・電話番号）をご登録ください
  3. 期限内にご登録がない場合、当選は無効となり、補欠の方への繰り上げ当選とさせていただきます
  4. 専用URLは当選者ご本人のみが使用できます。第三者に転送・共有しないでください
  5. 発送先情報は一度ご登録いただくと変更できません。変更が必要な場合は第13条の窓口までご連絡ください

第8条（賞品の発送）

  1. 発送先情報のご登録確認後、順次発送いたします（発送時期の目安：当選者確定後、順次）
  2. 発送は日本国内に限ります
  3. 次の場合、賞品の再発送は行いません
    • ご登録いただいた住所の誤記・不備により賞品が届かない場合
    • 転居・長期不在等により、保管期間の経過後に賞品が当方へ返送された場合
  4. 賞品の輸送中に生じた破損・紛失については、配送業者の定めに従って対応いたします

第9条（応募の無効・失格）

次に該当する場合、応募または当選を無効とすることがあります。

  1. 応募資格を満たしていないことが判明した場合
  2. 虚偽の情報を登録して応募した場合
  3. 複数のメールアドレスを使用する等、不正な手段により重複して応募した場合
  4. 自動化されたプログラム等による応募が行われた場合
  5. 当方または第三者に対する迷惑行為・誹謗中傷等が確認された場合
  6. その他、本規約に違反する行為があった場合

第10条（個人情報の取扱い）

ご応募にあたって取得した個人情報は、別途定めるプライバシーポリシーに従って適切に取り扱います。当選者への連絡および賞品の発送以外の目的には使用いたしません。

第11条（免責事項）

  1. 通信環境・回線の不具合、システム障害等により応募が正常に受け付けられなかった場合、当方は責任を負いません
  2. 応募者が入力したメールアドレスの誤記等により当選通知が到達しなかった場合、当方は責任を負いません（迷惑メールフォルダもご確認ください）
  3. 天災地変その他やむを得ない事由により、本企画の内容変更・中止を行う場合があります
  4. 本企画への参加により応募者に生じた損害について、当方の故意または重大な過失による場合を除き、当方は責任を負いません

第12条（本規約の変更）

応募期間中の本規約の変更は原則として行いません。ただし、やむを得ない事情により変更する場合は、応募ページに掲示してお知らせします。
